# Algorithms and correctness

- **Protocol construction:** O(k|Σ|) edges for bounded retry k; runtime uses an edge search O(|E|), constant for a fixed configured model. Explicit denial self-loops make δ total. State/guard invariants are exercised by integration tests.
- **Reachability/dead states:** forward reachability and reverse accepting reachability. A dead state cannot reach an accepting state; legitimate terminal logout/lock states may be dead by design. This implementation filters edge lists, so traversal can cost O(VE), rather than claiming adjacency-list O(V+E).
- **Safety BFS:** at most 8|Q| distinct product nodes. First violation has minimum edge count because every event has unit cost. Implementation scans outgoing edges and copies paths; graph size is capped at 100 states/3,000 edges.
- **Regex parsing:** shunting-yard with AST creation. Quantifier expansion contributes expanded size, not merely raw source length. Limits: source 256 chars, repeat 100, cloned AST 1,500 nodes, subset DFA 2,000 states. ASCII scope is explicit.
- **Thompson:** structural induction on literals, concatenation, alternation, star, plus and optional establishes language preservation. Empty expression denotes epsilon.
- **Epsilon closure/elimination:** graph reachability; δ'(q,a)=ε-closure(move(ε-closure(q),a)); q accepts iff its closure intersects original F. Educational elimination retains the eNFA container type with zero epsilon edges.
- **Subset construction:** each reachable DFA state represents exactly the active NFA set after the consumed prefix; accepting iff that set intersects F. Exponential worst-case state count is unavoidable.
- **Minimization:** repeated partition refinement (Moore-style), NOT Hopcroft's work-list algorithm. Split by acceptance/rule output then transition partition signatures until stable. Worst-case refinement O(|Σ||Q|²), excluding ancillary searches. No O(n log n) claim. Preserved multi-rule semantics group winning rule labels.
- **GNFA elimination:** R_ij ← R_ij ∪ R_ik(R_kk)*R_kj. null means empty language, empty string means epsilon. Union with epsilon becomes optional. State/expression limits report omission instead of inventing a regex. Expanded explicit alphabet labels are used; regex output can grow exponentially.
- **Right-linear grammar:** a DFA edge q --a→ r gives A_q → a A_r; accepting states give epsilon. Character-class labels are finite terminal classes in the displayed grammar.
- **Mealy → Moore:** split destinations by incoming output; add an INIT state. Ignore initial output for trace equivalence. At most 1+|Q||O| states.
- **CFG simplification:** fixed points remove nongenerating and unreachable nonterminals. This is a scoped useful-symbol simplifier, not full epsilon/unit-production elimination. CNF/GNF are constructive examples for a^n b^n, not arbitrary grammar conversion.
- **PDA:** stack invariant is exactly the unmatched BEGIN prefix. Matching END removes its top. O(n) execution and O(depth) live stack; trace copies increase total storage to O(n²).
- **TM:** one rule per configuration, at most budget steps. Unary successor O(n); matching a^n b^n O(n²). Stored full tape snapshots cost more than the live sparse tape. Non-halting cannot be inferred from budget exhaustion.
- **PCP:** bounded breadth-first tile enumeration; prefix-incompatible pairs are safely pruned because appending cannot repair the first unequal character. O(t^d) candidate bound. No solution by depth d is UNKNOWN for the unbounded problem.
- **Scanner caveat:** fixed-DFA whole-string recognition is linear for fixed machine size. Restarting substring search can be quadratic; legacy scanner claims of universal linear scanning are superseded.
